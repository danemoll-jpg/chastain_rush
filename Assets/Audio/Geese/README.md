# Goose honks

Drop the goose honk clips here (Dan's ElevenLabs clips). Names must start with `goose_honk`
and end in `.wav`, `.ogg` or `.mp3`, for example `goose_honk_01.wav`, `goose_honk_02.wav`.

Every matching clip is used: each honk picks one at random, with a little pitch variation,
and no more than three play at once. With no clips here the geese make no sound.

After adding or changing clips, run **Chastain Rush > Build Map** (or **Build Executable**)
so the scene and the exe pick them up.

**No rebuild (Round 15):** drop the same kind of files into
`%USERPROFILE%\AppData\LocalLow\Chastain Rush\Chastain Rush\Sounds\Geese\` instead. The game reads that
folder every time it starts and adds those honks to any built in from here. The folder (with a READ ME)
appears after the game has been started once.
